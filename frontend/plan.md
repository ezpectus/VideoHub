
##  Розробник 1: "Core Video Experience" (Плеєр, Навігація та Контент)
*Фокус: як користувачі знаходять та дивляться контент.*

- [ ] **Фільтрація відео за категоріями**
  - Дописати логіку в `app/page.tsx`.
  - Фільтрувати список відео за обраною `activeCategory` локально або через запит до бекенду.
- [ ] **Блок рекомендацій "Up next"**
  - Оновити `app/video/[id]/page.tsx`.
  - Замінити заглушку на виклик API, що підтягує список інших відео.
  - Відрендерити список через міні-компоненти (наприклад, створити `VideoListCompact`).
- [ ] **Глобальний пошук (Search Bar)**
  - Додати поле пошуку в `Navbar.tsx`.
  - Створити сторінку `app/search/page.tsx`, що парсить параметр URL (наприклад `?q=query`) та відображає відфільтровану сітку відео.
- [ ] **Нескінченний скрол (Infinite Scroll) або Пагінація**
  - Додати довантаження відео при скролінгу на головну сторінку та в результати пошуку.
- [ ] **Кастомний відеоплеєр**
  - Переробити інтерфейс `components/VideoPlayer.tsx`.
  - Приховати дефолтні HTML5-контроли (`controls={false}`) і написати власні кнопки "Play/Pause", розгортання на повний екран та стилізовану лінію прогресу.

## Розробник 2: "User & Social Interaction" (Соціальні фічі та Профіль)
*Фокус: користувацький досвід (UX), взаємодія юзерів та управління власним контентом.*

- [ ] **Лайки для відео**
  - Додати API-методи для лайків у `services/apiClient.ts`.
  - Оновити `app/video/[id]/page.tsx`: додати UI кнопок лайка та логіку їх перемикання (плюс оптимістичне оновлення UI).
- [ ] **Сторінка автора (Канал: `/user/[id]`)**
  - Створити нову сторінку для каналу користувача.
  - Відображати аватар, ім'я автора та відео, відфільтровані по `authorId`.
  - Зробити аватарки та імена користувачів клікабельними посиланнями на цю сторінку.
- [ ] **Dashboard / Управління контентом**
  - Створити розділ "Мої відео" (Dashboard) для авторизованого користувача.
  - Реалізувати можливість редагування (React-форма для заголовка/опису) та видалення свого відео з підтвердженням.
- [ ] **Покращення Upload (Thumbnails)**
  - Оновити `app/upload/page.tsx`.
  - Додати можливість одночасного завантаження відеофайлу та картинки обкладинки (thumbnail).
- [ ] **Історія переглядів (Watch History)**
  - Створити сторінку `/history`.
  - Записувати ID переглянутих відео локально (наприклад, у `localStorage`) і виводити сітку відео на цій сторінці.
